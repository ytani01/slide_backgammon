## 検索と取得の記録

- Commons: API の全文検索（`filetype:bitmap` ＋ backgammon／tavla／tavli／cafe／bar／lounge／interior など約 30 語）、カテゴリ `Backgammon`・`Backgammon boards`・`People playing backgammon` と国別カテゴリの全ファイルを、横 1600px 以上で絞って確認した（縮小画像で目視）。全文検索は本文を拾うため、PDF と古い書籍が大量に混じる。
- Unsplash: API は認可（キー）が必要、HTML は直接の取得が bot 判定（Anubis）で止まるため、回避していない。`WebSearch`・`WebFetch`（検索結果と一覧ページの文章化）で題・作者・ページ URL・画像 URL を得て、公開の画像 CDN（images.unsplash.com）から縮小画像を取得した。
- Pexels: 直接の取得は Cloudflare のチェックで止まる（403）ため回避していない。`WebFetch` で一覧・写真ページ（作者・原図の大きさ・ライセンス）を得て、公開の画像 CDN（images.pexels.com）から取得した。
- 上の Unsplash・Pexels の作者・ライセンスは `WebFetch` の要約から書いている（ページそのものは開いていない）。スライドに載せる前に、元ページで作者名の表記を確認してほしい。

## 判断が要る点

1. 「現代的な室内」を最優先にすると、Commons だけでは足りない。Unsplash・Pexels の写真（表記不要のライセンス）を採用してよいか。
2. `unsplash1.jpg` を採るなら、16:9 に切るときに上端のロゴを落とす切り方でよいか（落とすと右上の看板も消える）。
3. 顔が小さく写る `10129692`（モダンなリビングで最も主題に近い）を、顔を切り落として使う案もある。使うなら依頼してほしい。
