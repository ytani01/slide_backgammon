## きっかけ

利用者の指示（2026-10-02）: 2 枚目のスライドで、相手側の矢印とゴールも色を変えて書く。参考の動画
（https://youtu.be/xEzWfahBAaE 、TODO-020）のように矢印を動かす。動画の 12〜26 秒を 0.5 秒ごとに
抜いて見ると、黒と赤の U 字の矢印が先端の矢じりごと始点から伸び、描き終わると繰り返していた。
色はオレンジ、動きは 2 本同時に繰り返す、を利用者が選んだ。

## やったこと

`slides/backgammon.js` の「バックギャモンとは」で、

- 矢印 1 本を描く `flow()` を足した。線は `pathLength="1"` にして SMIL の `animate` で
  `stroke-dashoffset` を 1.01 → 0 に動かし、矢じりは `animateMotion`（`rotate="auto"`）で同じ速さで
  線の先端に付けて動かす。1 周 3.5 秒で、0.7 の時点で描き切り、残りは止める。1.01 から始めるのは、
  長さ 0 の dash の丸い端が始点に点として出るのを避けるため
- 白（緑）は右上 → 上の段を左へ → 下の段を右へ → 右下のゴール。茶色（オレンジ）はその外側を
  右下 → 下の段を左へ → 上の段を右へ → 右上のゴール。前の `marker` の矢じりはやめた
- 右上にオレンジの「ゴール」の札を足し、キャプションを「駒が進む向き（白と茶色は逆向き）」にして、
  白・茶色の字を矢印の色にした
- 利用者の指示「もっと大回りにして」で、2 本とも盤の中央の帯から三角の上まで広げた
  （白は y=250 / 500、茶色は y=170 / 580）

## 確かめたこと

- verifier（Playwright）: 幅 1280px で t=0・1.2・3.0 秒、幅 412px で t=3.0 秒を撮り、
  始点に点が出ないこと、矢じりが線の先端に乗って進むこと、2 本の向きが写真の駒の配置と合うこと、
  札とキャプションが読めることを確かめた。止めずに動いていることも `getCurrentTime()` で確かめた
- 詳細は [archives/agents/TODO-071/](../agents/TODO-071/README.md)

## 残ること

- 幅 412px では矢印が小さく、細部は見分けにくい（verifier の報告。実害は未確認）
- 再生を一時停止しても、矢印の動きは止まらない（SMIL は player.html の一時停止とつながっていない）
